# ChingYingAddons - Releases

Download host for ChingYingAddons, a Fabric mod for Hypixel SkyBlock dungeons.

This repository holds **release artifacts only** - there is no source here. Each release is
published automatically by the mod's relay server when a new build is deployed.

## Download

Grab the latest `.jar` from the [Releases page](../../releases) and drop it into your `mods/`
folder alongside Fabric API and Fabric Language Kotlin.

The mod also updates itself: it checks for a newer version on launch and pulls it automatically,
so this page is only needed for a first install.
